# Contributing to B2C Solution

Thank you for your interest in contributing to B2C Solution.

B2C Solution welcomes useful, secure, and well-maintained contributions to eligible open-source projects and repositories.

> **Note:** Not every B2C Solution repository is open for external contributions. Always check the repository's individual `README.md` and contribution instructions before submitting changes.

---

## 1. Before You Start

Before contributing:

1. Read the repository's `README.md`.
2. Check whether external contributions are permitted.
3. Review the applicable license.
4. Review the `CODE_OF_CONDUCT.md`.
5. Check existing Issues and Pull Requests.
6. Avoid duplicating existing work.

---

## 2. Types of Contributions

Depending on the repository, contributions may include:

- Bug fixes
- Security improvements
- Documentation
- UI/UX improvements
- Performance improvements
- Tests
- Developer tooling
- Feature proposals
- Code improvements
- Other approved improvements

---

## 3. Security Issues

Do **not** publicly create an issue containing sensitive security information.

Security vulnerabilities should be reported privately according to:

`security/RESPONSIBLE_DISCLOSURE.md`

Security reports should be sent to:

**b2csolution2436@gmail.com**
